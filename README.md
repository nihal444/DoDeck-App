# 📋 DoDeck – Flutter To-Do App

**DoDeck** is a cross-platform mobile app built with Flutter that helps students manage their tasks efficiently. The app features task creation, editing, deletion, theme customization (dark/light), and persistent storage using SQLite and SharedPreferences.

## 🚀 Features

- ✅ Add, edit, and delete tasks
- 🌗 Light and dark theme support
- 💾 Persistent local storage using SQLite
- 🔄 State management with Provider
- 📱 Fully responsive UI for Android and iOS

## 🧱 Technologies Used

- [Flutter](https://flutter.dev/)
- [Provider](https://pub.dev/packages/provider)
- [sqflite](https://pub.dev/packages/sqflite)
- [shared_preferences](https://pub.dev/packages/shared_preferences)
- [path](https://pub.dev/packages/path)
